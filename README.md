# Final Project - Emotion Detection Application

## Project Description
This is the Final Project for the Software Engineering course, where an AI-powered Emotion Detection web application is developed using IBM Watson NLP and Flask.

## Objectives
* Deploy an emotion detection application using Watson NLP API.
* Format output responses from the API into structured Python dictionaries.
* Build a web interface using the Flask framework.
* Incorporate robust error handling for empty string inputs.
* Conduct unit testing and static code analysis (Pylint).
